# Assets

This directory is reserved for repository-owned visual assets such as diagrams, badges, or figures that improve navigation.

Do not copy paper figures, publisher artwork, company logos, screenshots, or other third-party material here unless its license and attribution requirements have been verified. Prefer linking to the original source. Every added asset should include its provenance, license, and purpose in this file.

The initial release intentionally contains no image assets; the main README uses text and externally rendered status badges only.
